# kiosk_firmware
free open source OS for kiosks  

## setup
to enter the kiosk setup mode, you need to hold down a special key combination. it is intentionally made very complicated to prevent accidental enter  
you need to hold down this combination of 5 buttons for 5 seconds to get into the kiosk settings  
or press the power button  
hotkey: CommandOrControl+Meta+Shift+S+O
